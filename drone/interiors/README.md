# Interior shots

You do not have to pre-copy photos into this folder.

The app includes an upload panel and stores photographs in IndexedDB.

Recommended shot categories:

- back door / rear entry
- kitchen
- dining area
- living room
- powder room
- basement recreation room
- basement den / flex room
- basement bathroom
- bedroom 1
- bedroom 2
- shared upper bathroom
- primary bedroom
- primary walk-in closet
- primary ensuite
- roof deck

For the `panorama` shot type, upload a 2:1 equirectangular image, for example:

```text
4096 x 2048
8192 x 4096
```

Normal photographs should use `flat`.
